# field-notes-lab

Tool-tier standalone app (port 7804): a library of Markdown pages about our apps and what we learned. Mock = the sanitized pages in `pages/`; Real = the owner's local folder of full notes (`FIELD_NOTES_DIR`), read-only, loopback only.

- Run: `./scripts/run.sh` (http://127.0.0.1:7804/) or `HOST_PORT=7804 docker compose up --build -d` (OrbStack, Mock only). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest against the real server in a child process; repo scans = `node --test scripts/*.test.mjs`). Preflight: `npm run doctor`. UI standard: `bash scripts/check-ui-standard.sh` (vendored `web/src/standalone-ui.css` must equal the canonical copy on GitHub origin/main of AI-DEMO-Standalone; re-vendor from origin, then `--pin`).
- Server: `pages.js` (only `*.md` directly in the folder, safe names, symlinks only to files in the same folder, 512 KB / 20,000-line caps, read per request), `frontmatter.js` (tiny YAML subset, no eval), `config.js` (`FIELD_NOTES_DIR` from env or `~/Development/.env` / `STANDALONE_ENV`; Real refused off loopback and inside the repo; hints never echo the path), `app.js` (info, mode, pages, page, raw), `safety.js`, `netguard.js` (zero outbound in both modes), `doctor.js` (also fails on an unsanitized or incomplete shipped page), `health.js` (`demo-health/1`).
- Web: `lib/markdown.js` parses to a TREE (never HTML); `components/Markdown.jsx` renders it as React elements; `linkTarget()` decides what a link may be. Never use `innerHTML` or `dangerouslySetInnerHTML`; a repo test fails on it. Keep every scan linear (memoised closer search, no nested-quantifier regex on page text); the hostile tests time it.
- Rules that bite: one port, 7804, `127.0.0.1:` only (a test pins it); `POST /api/mode` is exactly `{ source }` (409 when Real is not configured); only `.example`/`.invalid` hosts, no UUIDs, no @mentions in `pages/` (scripts/pages.test.mjs); NEVER copy a page from the Real folder into `pages/` unsanitized; the Docker image has no volumes and no `FIELD_NOTES_DIR`.
- Theme tokens only (no colour literals in `app.css`), no purple, both themes, 375px; every control has a visible border (dark control contrast rule).
- `docs/shelf-entry.json` has no `catalogId` on purpose (no catalog row matches yet). The shelf registered this app (port 7804) in demo-shelf-LAB `data/demos.json` on 2026-11-08 (demo-shelf-LAB PR #11, 1dcf357). The port is 7804 because 7802 belongs to pingone-events-LAB (claimed on the board, also unregistered) and 7803 is its Vite dev default.
- No AI attribution anywhere (owner rule 2026-11-07).
